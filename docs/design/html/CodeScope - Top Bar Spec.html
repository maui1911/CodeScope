Tab states

Four states the tab row must handle

Active
feat/reporting

Focused & receiving input. Black fill, blue top rail with glow, close shown. Only one tab per group is active.

Hover
PestScope · main

Mouse over. #141414 bg, text to white, close reveals. No rail — hover ≠ focus.

Inactive
PestScope · main

Default rest. Transparent bg, label at 70% white. Status dot tells you it's still running in the background.

Waiting (attention)
bugfix/auth

Agent paused on a question. Dot is red and pulses (1.4s). This is the only moving element on the bar — movement = attention.

Build notes

Things that aren't obvious from the pixels

Per-group, not shared Each editor group owns its own tab bar. The bar is a child of the group, not of the window. When the focused group changes, the rail on the old group's active tab fades to #1F1F1F while the new group's lights up. One group, one active tab.
Rail bleeds past the tab The active-tab rail uses left/right: -4px; top: -4px on a ::before. That negative offset lets it span the gap between tabs visually, matching Framer's approach. Do not round it.
Status dots are semantic active (streaming) · idle (last response delivered, no activity) · wait (agent paused on a question). These drive the sidebar row state too — model the dot as a prop on the session, read by every surface that renders it.
Close on middle-click too Tabs close on ⌘W, middle-click, or the × button. Dragging a tab out of the bar starts a tab-drag (see the Tab Drag frame) — implement via pointer events, not native HTML5 drag, because the group layout needs to reflow under the cursor.
Overflow behavior When tabs would exceed the bar width, the whole row scrolls horizontally (no scrollbar, wheel + keyboard). Group controls always pin right via margin-left: auto. Never shrink tabs below 180px min; truncate the label instead.
Hover close doesn't hijack click The × button has a larger hit target (whole circle) but its click is stopped from propagating. Clicking anywhere else on the tab switches to it — even over the dot or close gap.

Suggested component shape

// One tab strip per editor group. Sessions live in the workspace store;
// this component just reads + emits events.

type Session = {
  id: string;
  project: string;        // "PestScope"
  branch: string;         // "feat/reporting"
  status: "active" | "idle" | "wait";
};

type TabBarProps = {
  sessions: Session[];     // tabs, in order
  activeId: string;        // which tab is focused
  groupCount: number;      // drives Close-group visibility
  onActivate(id: string): void;
  onClose(id: string): void;
  onReorder(ids: string[]): void;
  onNewTab(): void;
  onSplitRight(): void;    // moves activeId to a new group
  onCloseGroup(): void;
};
