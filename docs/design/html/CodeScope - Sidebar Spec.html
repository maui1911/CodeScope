Build notes

Things that aren't obvious from the pixels

Window-global The rail belongs to the window, not to any group. When the user splits the workspace into multiple editor groups, the sidebar does not duplicate. One rail, many groups.
Tree scrolls, foot is pinned The projects tree takes flex: 1 1 auto with overflow-y: auto. The foot (Overview + New Project) is pinned via margin-top: auto on the foot + 1px top border. Never let project rows push past the foot.
One accent, signaled twice The 2px session rail (left edge) and the 6px status dot both convey "this worktree has a session." Redundant but intentional — the rail scans at-a-glance vertically, the dot tells you which state.
Active ≠ has-session A row can be active (selected in the UI) without having a session, and vice versa. Both trigger the blue rail, but only active gets the #141414 fill. Keep them as two independent props.
Counts and dots propagate up The project-row count badge is the number of live sessions in that project. If any child is in wait, the project row shows a tiny red dot next to the count — so a collapsed project still tells you it needs attention.
Right-click Every worktree row has a context menu (see Context Menu frame). Opening it puts a subtle #141414 fill + 1px #2A2A2A inset on the row so you know which target the menu acts on.
Keyboard nav ↑↓ moves through flattened tree (projects + worktrees). ←/→ collapses/expands the parent. ↵ opens the selected worktree's session in the focused group. ⌘↵ opens in a new group.
Empty state When the projects array is empty, the rail hides the tree + section label entirely. Only brand + foot remain; the main area shows the empty-state design.

Suggested component shape

// Window-global. Reads the workspace store, emits events.

type SessionStatus = "active" | "idle" | "wait";

type Worktree = {
  id: string;
  branch: string;              // "feat/reporting"
  hasSession: boolean;
  status?: SessionStatus;      // only if hasSession
  changes: number;             // uncommitted; 0 → show "—" if no session
  sha?: string;                // short 7-char; used for meta fallback
};

type Project = {
  id: string;
  name: string;                // "PestScope"
  open: boolean;               // expanded?
  worktrees: Worktree[];
};

type SidebarProps = {
  projects: Project[];
  activeWorktreeId: string | null;
  overviewOpen: boolean;
  onToggleProject(id: string): void;
  onSelectWorktree(id: string): void;
  onContextWorktree(id: string, pos: {x:number;y:number}): void;
  onNewProject(): void;
  onToggleOverview(): void;
};

// DOM:
//   <aside class="sidebar">
//     <Brand />                              ← 48px, 1px bottom border
//     <div class="tree" />                   ← flex:1, overflow-y:auto
//       <SectionLabel>Projects</SectionLabel>
//       <ProjectRow /> <WorktreeRow x N />   ← repeat
//     <Foot />                               ← margin-top:auto, 1px top border
//       <OverviewBtn />
//       <NewProjectBtn />
//   </aside>
