Build notes

Things that aren't obvious from the pixels

Window-global, session-scoped One bar per window. Left cluster reads from the focused session (branch, git, diagnostics, model, tokens, runtime). Right-side agent roll-up reads workspace-wide. Don't mix scopes within a cluster.
Items hide, they don't placeholder Zero counts collapse entirely — no "0 errors" chip. The bar gets quieter when nothing's wrong, louder when it is. This is a feature; it makes anomalies pop.
Everything is clickable Every segment is a button with a 32px hit area. Branch → context menu · git → Diff panel · remote → Pull/Push · errors/warnings → Diagnostics panel · model → switcher · tokens → Context inspector · roll-up → Overview · bell → Notifications.
Icons are line, not filled 12px, 1.4 stroke, rounded caps/joins — matches the rest of the chrome. Don't pull from a filled-icon set; the density will feel wrong at this size.
Separators are structural, not decorative Hairlines between clusters (session context · diagnostics · model · agents · notifications), never between every item. Internal items share a gap of 14px, cluster boundaries add the 1×14 separator.
Overflow If width is tight (narrow window), collapse from the middle outward: runtime → warnings → remote → model name (becomes icon-only with tooltip). Branch, error count, and agent roll-up never collapse.
Don't animate the bar itself Ticking numbers (tokens, runtime) use font-variant-numeric: tabular-nums so digits don't jitter. The meter fills with a 300ms transition; everything else is static. The bar is a reference; it shouldn't compete with the terminal.
Tooltip on every cluster 300ms delay, dark popover above the bar. Expands the terse value: "+3 additions, −1 deletion across 2 files" — so novices can learn the vocabulary and experts get the short form.

Suggested component shape

// One bar per window. Reads from focused session + workspace.

type GitState = {
  dirty: { added: number; removed: number };
  remote: { ahead: number; behind: number } | "detached";
};

type Diagnostics = { errors: number; warnings: number };

type SessionCtx = {
  branch: string;
  status: "active" | "idle" | "wait";
  model: string;                // "claude-sonnet-4-5"
  tokens: { used: number; cap: number };
  runtimeSec: number | null;   // null when idle
};

type AgentRollup = { active: number; idle: number; wait: number };

type StatusBarProps = {
  session: SessionCtx;
  git: GitState;
  diagnostics: Diagnostics;
  agents: AgentRollup;            // workspace-wide
  unreadNotifications: number;

  onBranchClick(): void;
  onDiffClick(): void;
  onRemoteClick(): void;
  onDiagnosticsClick(severity: "error" | "warn"): void;
  onModelClick(): void;
  onTokensClick(): void;
  onOverviewClick(): void;
  onNotificationsClick(): void;
};
